# Informe de control de calidad — MEPROLIM

Este informe informa sobre la cobertura técnica, **no certifica precisión completa**.

- 650 páginas con contenido indexable (se omiten las 4 páginas preliminares de cada uno de los 4 PDF).
- 3928 códigos candidatos únicos, deduplicados por código normalizado.
- 974 códigos que aparecen en más de un catálogo.
- 1141 códigos con al menos un recorte de imagen asociado (asignación automática salvo la muestra contrastada).
- 8 códigos con imagen revisada en la muestra.
- 35 ejemplos de nombres comprobados en las páginas consultadas.

**Conflicto conocido:** FR0096 se asigna a dos denominaciones en el PDF verde. Se mantiene una sola ficha con aviso de discrepancia.

**Limitaciones:** la asociación completa código-nombre-imagen no está validada. Los recortes automáticos pueden mostrar un accesorio o artículo cercano. Para cada código se conserva al menos la página de origen y se generan vistas previas para inspección. No usar como catálogo definitivo de pedidos sin auditoría adicional.

**Publicación:** los catálogos y sus imágenes son material de terceros; confirmar permisos de reproducción antes de subir estos recursos a GitHub Pages público.
